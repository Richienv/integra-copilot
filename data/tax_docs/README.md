# Tax documents

Put official Indonesian tax guidance here as `.md` or `.txt` files, one document per file: PPN, PPh 21/23,
e-Faktur and Coretax guidance from pajak.go.id, and the regulations themselves.

- Convert PDFs to text first, then read the result: remove page headers, keep tables as one row per line.
- Add the source address and the date you downloaded it at the top of each file. Tax rules change.
- The copilot answers tax questions only from these files and cites them. With no files here, it says so.

This repository ships no tax text of its own.
